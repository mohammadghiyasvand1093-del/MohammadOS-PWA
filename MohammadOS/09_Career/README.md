**Version:** 1.0
**Status:** Active

---

# Purpose

The Career module governs the long-term professional development of Mohammad.

Its purpose is to transform technical learning into employable skills, professional experience, financial independence, and international career opportunities.

This module defines **what career is being built**, **why it is being built**, and **how progress is measured**.

---

# Career Mission

Build a professional engineering career following a structured path:

```
IT Fundamentals
        ↓
Backend Development
        ↓
DevOps Engineering
        ↓
DevSecOps Engineering
        ↓
Senior Engineer
        ↓
International Career
```

No major deviation from this path is allowed without passing the Decision Engine.

---

# Career Objectives

## Technical Mastery

Develop production-ready engineering skills.

Knowledge is not considered complete until it can be applied in a real project.

---

## Professional Experience

Accumulate experience through:

* Personal projects
* Open Source contributions
* Freelance work
* Engineering employment

Experience must be documented.

---

## Portfolio

Maintain a public portfolio demonstrating engineering capability.

Portfolio assets include:

* GitHub repositories
* Technical documentation
* Infrastructure projects
* Automation scripts
* DevOps labs

---

## Professional Reputation

Build credibility through consistent output.

Examples:

* GitHub activity
* Technical writing
* Certifications
* Community participation
* Professional references

Reputation compounds over time.

# Career Rules

1. Skills must produce measurable output.
2. Projects are more valuable than tutorials.
3. Portfolio is more valuable than certificates alone.
4. Consistency beats intensity.
5. Career decisions must align with the Mission.
6. Every major skill should eventually contribute to:

   * Employment
   * Income
   * Portfolio
   * Professional reputation
