# Constitution

**Version:** 2.0
**Status:** Active Foundation

---

# Purpose

The Constitution is the highest authority inside MohammadOS.

Everything in the system — dashboards, roadmaps, projects, schedules, AI assistants, reviews, and daily decisions — must comply with the Constitution.

This directory contains the permanent documents that define who Mohammad is, what he is building, and how every important decision should be made.

The Constitution is intentionally stable and should only change after deliberate review.

---

# Documents

| Document           | Purpose                                    |
| ------------------ | ------------------------------------------ |
| 01_Principles      | Core principles that guide every action    |
| 02_Mission         | Long-term mission, vision and end-state    |
| 03_Decision_Rules  | Framework for making difficult decisions   |
| 04_Non_Negotiables | Rules that cannot be violated              |
| 05_Identity        | Personal identity and operating philosophy |

---

# Hierarchy

When two documents conflict, always follow this order:

1. Constitution
2. Profile
3. Roadmap
4. Dashboard
5. Projects
6. Daily Plans

Higher-level documents always override lower-level documents.

---

# Design Philosophy

The Constitution exists to eliminate emotional decision-making.

Its purpose is not motivation.

Its purpose is consistency.

Every document inside MohammadOS should ultimately support the mission defined here.

If a task, habit, project, or opportunity does not serve the Constitution, it should be questioned before being accepted.

---

# Maintenance Policy

The Constitution is not a daily document.

Review it:

* Every 6 months
* After major life events
* Before changing long-term goals

Frequent editing is discouraged.

Stability creates clarity.
