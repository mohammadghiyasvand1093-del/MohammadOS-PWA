# Purpose

This glossary defines the vocabulary used throughout MohammadOS.

Every important term has one official meaning.

Using consistent terminology prevents misunderstanding between documents, AI assistants, and future versions of the system.

---

# Core Terms

## MohammadOS

The complete personal operating system governing planning, execution, learning, finance, career, health, and decision-making.

---

## Constitution

The highest authority of MohammadOS.

Contains permanent principles, mission, identity, and decision rules.

Changes very rarely.

---

## Mission

The long-term purpose of the system.

Everything inside MohammadOS must ultimately support the Mission.

---

## Roadmap

The strategic plan connecting today's work to the long-term Mission.

Defines phases, milestones, and Gates.

---

## Dashboard

The operational control center.

Shows today's priorities, active Gate, progress, and execution status.

---

## Gate

A structured learning phase with:

* Defined objective
* Required skills
* Completion criteria
* Deliverables

Only one major Gate may be active at a time.

---

## Milestone

A measurable achievement marking meaningful progress toward the Mission.

Examples:

* Complete Linux Fundamentals
* Publish first portfolio project
* Obtain first engineering internship

---

## Deep Work

Focused, uninterrupted work performed without distraction.

Deep Work is measured by quality and duration, not by time spent at a computer.

---

## Review

A structured evaluation of system performance.

Review periods include:

* Daily
* Weekly
* Monthly
* Quarterly
* Annual

---

## Module

A major functional component of MohammadOS.

Examples:

* Constitution
* Dashboard
* Roadmap
* Finance
* Career

---

## Blueprint

The architectural documentation describing how MohammadOS is designed.

Blueprint explains the system.

Dashboard executes the system.

---

## Execution

The process of turning plans into measurable outputs.

Execution is the highest priority activity after planning is complete.

---

## Output

Any measurable result created by execution.

Examples:

* GitHub commits
* Projects
* Documentation
* Certificates
* Income
* Completed Gates

---

## Planning Hell

The condition where planning continues without producing meaningful outputs.

Planning Hell is considered a system failure.

---

## Active Gate

The current learning objective receiving primary focus.

All other major learning tracks remain inactive until this Gate is completed.

---

## Critical Path

The shortest sequence of tasks required to reach the current strategic objective.

Work outside the Critical Path must be minimized.

---

## AI Council

The collection of AI assistants used within MohammadOS.

Each AI has defined responsibilities and authority boundaries.

No AI overrides the Constitution.

---

## System State

The current operational condition of MohammadOS.

Includes:

* Current Phase
* Active Gate
* Dashboard Status
* Review Status
* Version

---

## Version

The official revision number of a document or module.

Format:

Major.Minor.Patch

Example:

v1.2.0

---

# Naming Convention

Documents use descriptive names.

Folders use numeric prefixes to preserve order.

Examples:

* 00_Constitution
* 03_Dashboard
* 08_Finance

---

# Summary

Every document inside MohammadOS should use the terminology defined here.

If a new concept becomes part of the system, it must first be added to the Glossary before becoming official.
