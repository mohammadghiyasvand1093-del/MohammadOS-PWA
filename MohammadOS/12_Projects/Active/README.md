# Purpose

The Active section contains all projects currently under development.

Only projects that are actively receiving work should appear here.

---

# Rules

1. Every active project must have its own project document.
2. Every project must originate from the Backlog.
3. Active projects should be reviewed regularly.
4. Completed projects must be moved to Completed.
5. Abandoned projects must return to Backlog or be Archived.
