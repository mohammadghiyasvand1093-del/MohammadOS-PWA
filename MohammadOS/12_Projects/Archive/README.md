# Purpose

The Archive contains projects that are no longer actively maintained.

Archived projects remain part of MohammadOS for historical reference, documentation, and lessons learned.

---

# Rules

1. Archived projects are read-only.
2. Documentation must remain complete.
3. No active development occurs in this section.
4. Archived projects may be restored if needed.
5. Every archived project must include an archive reason.

# Archive Criteria

A project may be archived when:

- It has been superseded by a newer project.
- It is no longer relevant.
- Maintenance has permanently stopped.
- The project has historical value only.

---

# Restoration Policy

An archived project may return to Active only after:

- A new review.
- Updated planning.
- Roadmap approval.
