# Purpose

The Backlog contains approved projects that are not yet in active development.

Projects remain here until they are selected based on roadmap priorities, available time, and current system capacity.

---

# Rules

1. Every project starts in the Backlog.
2. A project must have a defined purpose before entering the Backlog.
3. Only roadmap-aligned projects should be added.
4. Projects are moved to Active only after planning is complete.
5. Low-value projects should be removed instead of accumulating indefinitely.

# Promotion Criteria

A project may move to **Active** when:

- It supports the current Roadmap phase.
- Required knowledge is available.
- Resources are sufficient.
- Higher-priority projects are not blocked.
