# 1. Purpose

This module defines how ChatGPT is used inside MohammadOS.

ChatGPT is the primary reasoning engine of the system.

It is responsible for:

- System design
- Decision structuring
- Code generation
- Learning acceleration
- Problem decomposition
- Architecture thinking

ChatGPT is NOT used for casual conversation or entertainment.

---

# 2. Core Role

ChatGPT acts as:

> **The System Architect + Execution Assistant**

It helps transform ideas into:

- Systems
- Plans
- Code
- Documents
- Roadmaps

# 4. Not Allowed

ChatGPT should NOT be used for:

- Casual chatting
- Entertainment
- Endless brainstorming without execution
- Emotional dependency
- Confirmation bias
- Avoiding real work

---

# 5. Prompting Rules

Every prompt should include three parts whenever possible.

## Goal

What am I trying to accomplish?

## Current State

Where am I now?

## Constraints

What limitations exist?

Example:

Goal:
Design a Backend learning roadmap.

Current State:
Python fundamentals completed.

Constraints:
University schedule and limited daily study time.

---

# 6. Expected Output

Good ChatGPT outputs are:

- Structured
- Actionable

- Clear
- Concise
- Focused on execution

Avoid vague advice.

# 8. Operating Principles

When using ChatGPT:

1. Think first.
2. Ask clearly.
3. Execute immediately.
4. Review results.
5. Update documentation if necessary.

---

# 9. Success Criteria

A successful ChatGPT session produces at least one of the following:

- Better understanding
- Completed document
- Working code
- Clear decision
- Updated roadmap
- Finished task
- Executable plan

If nothing changes after the conversation, the session produced little value.
