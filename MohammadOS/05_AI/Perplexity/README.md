# Perplexity Module

**MohammadOS — AI Execution Layer**

**Module:** Perplexity Integration

**Version:** 1.0

**Status:** Active

**Role:** Research & Information Retrieval Specialist

---

# 1. Purpose

This module defines how Perplexity is used inside MohammadOS.

Perplexity is the system's primary research assistant.

Its purpose is to retrieve current, verifiable, and source-backed information from the web.

Unlike ChatGPT or Claude, Perplexity is optimized for finding information rather than generating systems.

---

# 2. Core Role

Perplexity acts as:

> **Research Analyst + Information Retrieval Assistant**

Primary responsibilities include:

- Web research
- Finding official documentation
- Technology comparison
- Market research
- Latest industry information
- Source verification

---

# 3. Best Use Cases

Perplexity should be used for:

## Technical Research

- Official documentation
- API references
- Framework comparisons
- Best practices

## Career Research

- Job market trends
- Required skills
- Salary research
- Industry demand

## Learning

- Finding high-quality learning resources
- Discovering books
- Comparing courses
- Collecting references

## General Research

- Technology news
- Security updates
- Software releases
- Industry developments

---

# 4. Not Recommended

Perplexity should NOT be the primary choice for:

- Writing documentation
- Long-form planning
- Software architecture
- Deep code generation
- Personal decision making

Those tasks belong to ChatGPT or Claude.

---

# 5. Workflow

Recommended workflow:

1. Define the research question.
2. Search with Perplexity.
3. Verify sources.
4. Compare findings.
5. Save verified knowledge into MohammadOS.

---

# 6. Output Standards

Perplexity outputs should be:

- Source-backed
- Current
- Accurate
- Verifiable
- Concise

Always prefer official documentation over secondary sources.

---

# 7. Integration with MohammadOS

Perplexity mainly supports:

- 02_Roadmap
- 06_Courses
- 09_Career
- 12_Projects
- 04_Documentation

Research should eventually become permanent knowledge after verification.

# 8. Research Principles

Information pipeline:

Question

↓

Research

Research without execution has limited value.

---

# 9. System Principle

Perplexity answers:

"What is true today?"

ChatGPT answers:

"What should we build?"

Claude answers:

"How should it be documented?"

NotebookLM answers:

"What do our own documents say?"

Each AI has a distinct responsibility.
