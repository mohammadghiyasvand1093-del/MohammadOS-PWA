# Claude Module

**MohammadOS — AI Execution Layer**

**Module:** Claude Integration

**Version:** 1.0

**Status:** Active

**Role:** Documentation & Deep Analysis Specialist

---

# 1. Purpose

This module defines the role of Claude inside MohammadOS.

Claude is the system's primary documentation and long-form reasoning assistant.

Its strength is transforming ideas into well-structured, readable, and professional documents.

Claude complements ChatGPT rather than replacing it.

---

# 2. Core Role

Claude acts as:

> **Documentation Architect + Deep Analysis Assistant**

Primary responsibilities include:

- Long-form documentation
- Technical writing
- System architecture documents
- Deep reasoning
- Large document analysis
- Specification refinement

---

# 3. Best Use Cases

Claude should be used for:

## Documentation

- README files
- Technical specifications
- Markdown documentation
- Architecture documents
- Design documents

## Analysis

- Reviewing long documents
- Finding inconsistencies
- Improving clarity
- Refining structure
- Gap analysis

## Writing

- Professional writing
- Technical editing
- Rewriting for clarity
- Improving organization

## Planning

- Breaking large projects into modules
- Organizing documentation
- Designing documentation systems

---

# 4. Not Recommended

Claude should NOT be the primary choice for:

- Live debugging
- Rapid coding iterations
- Small programming questions
- Quick factual lookups
- Web research

Those tasks are better suited to ChatGPT or Perplexity.

---

# 5. Workflow

Recommended workflow:

1. Design with ChatGPT.
2. Refine with Claude.
3. Review manually.
4. Save to MohammadOS.

---

# 6. Output Standards

Claude outputs should be:

- Well structured
- Consistent
- Professional
- Easy to maintain
- Markdown-friendly

Every document should be ready for long-term storage.

---

# 7. Integration with MohammadOS

Claude primarily supports:

- 00_Constitution
- 04_Documentation
- 02_Roadmap
- 03_Dashboard
- 12_Projects

Claude is responsible for improving documentation quality across the entire system.

---

# 8. Quality Checklist

Before accepting Claude output, verify:

- Is the structure logical?
- Is anything duplicated?
- Is terminology consistent?
- Is the document maintainable?
- Does it match MohammadOS standards?

If any answer is "No", revise before saving.

---

# 9. System Principle

Claude optimizes clarity.

It should improve existing ideas rather than create unnecessary complexity.
